# 资产出图提示词草案

本文件用于后续接入图像生成能力时直接出正式美术资产。

## 1. 主立绘

### 用途

- 角色设定主图
- 项目主页或聊天页角色展示

### Prompt

二次元美少女虚拟助手角色设定图，半未来感日系风格，气质温柔机灵，有一点舞台歌姬感，长时间陪伴型 AI 搭档设定，清透但不幼态，精致五官，灵动眼神，发型层次明显，服装兼具聊天陪伴感与轻演出感，主色以墨灰、雾白、薄荷绿、珊瑚红点缀，局部少量金色配件，站姿自然，适合延展为聊天头像、立绘、桌宠和贴纸包，高清，高完成度，角色设计统一，背景简洁

### Negative Prompt

低幼卡通、Q 版比例、厚重机甲、过度暴露、复杂背景、杂乱饰品、写实照片感、模糊、畸形手部、乱码文字、水印

## 2. 聊天半身头像

### 用途

- 聊天页顶部角色头图
- 消息气泡头像

### Prompt

二次元美少女聊天助手半身像，镜头靠近胸像或肩部，表情温柔聪明，适合消息头像裁切，保留角色标志性发型和配色，日系清透上色，背景干净，轮廓清晰，适合圆形头像裁切

### Negative Prompt

全身远景、复杂背景、过暗打光、头像裁切困难、表情僵硬、多人构图、文字、水印

## 3. Q 版桌宠主形象

### 用途

- 页面右下角浮动桌宠
- 后续可扩展为待机、拖拽、点击反馈

### Prompt

Q 版二次元美少女桌宠，全身，三头身到四头身比例，清晰大眼，表情活泼可爱但不过分幼态，保留主角色发型与配色识别点，动作适合做待机桌宠，身体轮廓完整，便于后续拆分表情和动作帧，背景纯色便于抠图，高完成度，轮廓清楚

### Negative Prompt

复杂透视、遮挡身体、背景杂乱、过多道具、肢体缺失、模糊边缘、水印、文字

## 4. 桌宠动作扩展

建议至少补齐以下状态：

- 待机 idle
- 开心 happy
- 唱歌 sing
- 思考 think
- 生气 pout
- 困倦 sleepy
- 提醒 alert
- 庆祝 celebrate

## 5. 聊天气泡贴纸包

### Prompt

同一角色的聊天贴纸包，Q 版二次元美少女助手，表情夸张易读，包含开心、委屈、收到、好耶、等一下、交给我、偷偷看你、灵感来了等语义，背景干净，适合移动端聊天界面使用，风格统一，高对比轮廓

## 6. 当前实现说明

本次仓库内前端使用的是占位矢量形象，不是最终正式美术资产。后续一旦接入图像生成能力，可以直接基于以上提示词替换为正式图。
